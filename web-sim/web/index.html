前端无法启动

浏览器拒绝以这种方式加载页面脚本。最常见的原因是直接双击打开了 web\index.html（即 file:// 协议）， 此时 ES 模块会被 CORS 策略拦截。

正确做法是由后端托管页面后访问它：

  1. 启动后端：RobotServer.exe --port 8760 --web web
  2. 浏览器访问：http://127.0.0.1:8760/
